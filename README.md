# Pokémon Universe

Projet de fangame PC en pixel art : sept premières régions, Pokédex mondial, Méga-Évolutions et coopération asymétrique à deux joueurs.

## État réel

Développement en cours. Une campagne pilote originale nommée **Méridien** est en préparation. Le jeu complet demandé n'est pas terminé.

Les sources, crédits, tests et limites de la première version seront ajoutés dans le prochain commit.
